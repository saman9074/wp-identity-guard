## 1. Release Scope (`v0.1.0-alpha.1`)

`v0.1.0-alpha.1` publishes the completed **P01 Foundation** of **WP Identity Guard (Free)**:

- Versioned 6-table InnoDB (`utf8mb4`) database schema and `GET_LOCK()`-protected migration runner (`wpig_profiles`, `wpig_verifications`, `wpig_cards`, `wpig_otp_challenges`, `wpig_consents`, `wpig_audit_events`).
- `libsodium` `XChaCha20-Poly1305-IETF` AEAD encryption (`v1:<key_id>:<base64url>`), 6-segment `CanonicalAad`, `K1`/`K2` external keyring provider (zero WordPress salt fallback), `SensitiveValue`, normalization, purpose-separated `HMAC-SHA-256` fingerprinting, and display masking.
- Transactional `ProfileRepository` (`SELECT ... FOR UPDATE`), granular version counters (`identity_version`, `mobile_version`, `card_version`), and `D14` bound national-code uniqueness persisting across verification freshness expiry.
- `AuthenticationContext`, least-privilege capabilities (`manage_wpig_settings`, `view_wpig_reports`, `review_wpig_verification`), `AuthorizationService`, single-use same-process `VerificationAuthorityGrant`, and `ProfileAccessBoundary`.
- `AdminController`, non-autoloaded `SettingsRepository`, operational `DiagnosticsService`, append-only `AuditRepository`/`AuditService`, `ConsentRepository`, `PrivacyExporterService`, `PrivacyEraserService`, and `RetentionService`.

**Explicitly Not Included (Planned for `P02`–`P05`):** SMS OTP delivery, Shahkar provider adapters, bank card ownership provider inquiries, REST endpoints, and end-user account UI integrations. Do not use `v0.1.0-alpha.1` for production identity verification.
